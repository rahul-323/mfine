# MFine UI Clone

A UI-only Flutter recreation inspired by the MFine screenshots supplied in the conversation.

## Run

```bash
flutter pub get
flutter run
```

## Notes

- No backend, network API, authentication, or real payment flow is included.
- Navigation is implemented with `go_router`.
- Home uses `carousel_slider` and `smooth_page_indicator`.
- Screens are responsive using `MediaQuery`, `LayoutBuilder`, `Expanded`, and constrained content.
- Supplied screenshots were used as local visual references; the app is rebuilt with Flutter widgets instead of embedding full-screen screenshots.
